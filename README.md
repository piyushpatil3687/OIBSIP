# NEXORA - Landing Page

## OIBSIP Web Development & Design Internship

This project is a modern and responsive landing page developed as part of the OASIS INFOBYTE Web Development & Design Internship.

The landing page is designed for a fictional technology company named **NEXORA**, with a focus on modern design, responsive layouts, clean typography, and user-friendly navigation.

---

## 📌 Project Overview

NEXORA is a modern technology-focused landing page that presents a fictional company and its digital solutions.

The website includes a professional navigation bar, hero section, feature cards, company information, call-to-action section, and footer.

The project was developed using only HTML5 and CSS3.

---

## ✨ Features

- Fixed navigation bar
- Responsive design
- Hero section with headline and description
- Call-to-action buttons
- Features section with three feature cards
- About section
- Contact call-to-action section
- Professional footer
- Smooth scrolling navigation
- CSS Grid and Flexbox layout
- Mobile-friendly design
- Consistent color scheme and typography

---

## 🛠️ Technologies Used

- HTML5
- CSS3
